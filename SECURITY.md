# Política de Segurança — PortfolioHUB

Este documento estabelece as diretrizes de segurança e conformidade para o projeto acadêmico **PortfolioHUB**, desenvolvido para o Bootcamp UniCEUB.

## Versões Suportadas

Como este é um projeto de portfólio estático focado em fins educacionais e de demonstração profissional, apenas a versão mais recente na branch principal recebe atualizações.

| Versão | Suportada |
| :--- | :--- |
| 1.0.x (main) | ✔️ Sim |
| Versões anteriores | ❌ Não |

## Relatando uma Vulnerabilidade ou Falha

A integridade do código e a conformidade com as boas práticas de privacidade (incluindo diretrizes da LGPD) são prioridades neste projeto. Se você identificar qualquer vulnerabilidade de segurança, link quebrado com comportamento malicioso, ou exposição indevida de dados sensíveis, por favor, siga o procedimento abaixo:

1. **Não abra uma Issue pública** para relatar falhas críticas de segurança, evitando a exposição de riscos antes da correção.
2. Envie um relatório detalhado diretamente para o desenvolvedor responsável através do e-mail institucional ou canais de contato listados no arquivo `index.html`.
3. O relatório será analisado e a correção será aplicada via commit na branch `main` em até 48 horas.

## Práticas de Segurança Adotadas

* **Zero Credentials:** O código-fonte está livre de senhas, chaves de API ou dados pessoais estritos.
* **HTTPS Estrito:** Todos os ativos (currículo, apresentações e certificados) utilizam links de transporte criptografados.
