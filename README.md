### 🌐 `portfolio.html` — Portfólio Pessoal Web

**Tipo:** Página HTML estática  
**Tamanho:** 664 linhas · 19.8 KB  
**Linguagem:** HTML5 + CSS3 (sem dependências externas além de Google Fonts)

#### O que é
Página web completa que funciona como portfólio profissional interativo, apresentando as habilidades, formação e informações de contato de Rafael Guimaraens. Foi desenvolvida com design escuro moderno, animações CSS e layout responsivo para dispositivos móveis.

#### Seções da página

| Seção | Descrição |
|---|---|
| **Navbar** | Barra de navegação fixa com links internos, badge animado "Disponível para oportunidades" |
| **Hero** | Apresentação principal com nome, subtítulo, descrição, CTAs e estatísticas (19 anos / 2+ cursos / 5+ hard skills) |
| **Sobre mim** | Texto descritivo sobre trajetória, valores e diferenciais; cards com localização, formação, idiomas e interesses |
| **Hard Skills** | Barras de progresso visuais para Python, Matemática, Estatística, Inglês, Teoria Musical, R e SQL |
| **Soft Skills** | Grid de tags com habilidades comportamentais (liderança, adaptabilidade, comunicação, etc.) |
| **Formação & Certificações** | Timeline com CEUB, Intensivo de Cálculo 1 (UnB) e Jornada Python (Hashtag) |
| **Contato** | E-mail clicável, localização e botão de contato direto |
| **Footer** | Créditos e copyright |

#### Tecnologias utilizadas
- **HTML5** semântico (nav, section, footer, hr)
- **CSS3** com variáveis customizadas (`--bg`, `--accent`, `--surface`, etc.)
- **Google Fonts** — Space Mono (monospace) + Sora (sans-serif)
- **Animações CSS** — `fadeUp` com `animation-delay` escalonado para entrada suave
- **CSS Grid e Flexbox** para layout responsivo
- **Media queries** para adaptação em telas menores que 768px

#### Paleta de cores

| Variável | Cor | Uso |
|---|---|---|
| `--bg` | `#0a0a0f` | Fundo geral |
| `--surface` | `#111118` | Cards e superfícies |
| `--accent` | `#7c5cfc` | Roxo principal (destaques) |
| `--accent2` | `#c084fc` | Roxo secundário (números, orgs) |
| `--green` | `#4ade80` | Badge de disponibilidade |
| `--text` | `#e8e8f0` | Texto principal |
| `--muted` | `#8888a0` | Texto secundário |

#### Como visualizar
Basta abrir o arquivo `portfolio.html` diretamente no navegador, ou acessar via GitHub Pages (se ativado no repositório).
